# 产物的用途与收尾

创建文件前确定谁会阅读或使用它。普通推理、进度和研究摘要默认留在对话；用户要求、项目约定或后续执行确实需要时才保存。沿用已有记录，避免在规格、日志和总结中重复保存同一事实。

仍在使用的规格、任务、术语、决定、报告和复现材料属于有效记录。`.scratch`、`work`、`tmp` 等名字不能证明其中的文件可删除。任务完成只改变状态，不等于内容失去价值。

- 仍有用途：保留并更新，维护引用。
- 已结束活跃使用但有历史价值：按项目约定归档，保持可查；归档不是垃圾处理的默认答案。
- 已无用途且证据充分：在授权范围直接删除，不再制造永久备份。
- 用途不明或仍含未落实决定：保留，只询问影响处理的具体问题。

报告采用项目已有目录；新项目默认 `reports/`，可由 `.gnosis/project.json` 的 `reports` 覆盖。相同主题优先更新同一文件，确需保留版本时另存。报告放在工作区内，交付可点击路径；允许 CDN，不承诺依赖网络资源的功能离线可用。

临时探针、采集文件和提交草稿集中在项目约定的临时位置，记录足以判断用途的最少信息。任务收尾移除本次产生、已无用途的材料；持续需要的证据进入对应记录。避免采集或留存凭据及无关个人数据。

清理与迁移时，核对实际路径、引用、任务状态以及谁还在使用这些文件。保留用户与其他代理的已有改动，不跟随符号链接修改范围外目标。移动后维护有效引用；不为纯文件整理默认执行整个测试套件。
