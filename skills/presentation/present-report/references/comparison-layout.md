# 复杂比较的阅读层次

## 总览

首屏说明要决定什么、推荐方案、最重要的收益与代价，以及尚未验证的关键假设。让读者能直接找到下一步选择。用词与领域术语保持一致，首次出现的专门概念简短解释。

接着用同一张表比较现状与候选。列通常包括行为或结构变化、证据、预期收益、迁移成本、风险及验证方式；选取决定真正需要的维度。候选之间使用相同指标、单位和评价口径，不把主观评级包装成测量结果。

## 方案与图示

重要方案采用统一顺序呈现问题证据、设计变化、收益与代价、验证与迁移。前后图保持同一观察范围、实体命名、布局方向和视觉编码，突出变化的职责或数据流。图下解释改变后谁承担原来的复杂性，避免读者自行比对庞大图形。

每张图围绕一个问题。复杂系统先展示总览，再拆出相关局部；节点文字保持简洁，提供正文等价说明。性能比较标注输入、环境、样本、基线和误差，未经实验的收益写成待验证假设。

## 详细证据

默认展开推荐与主要备选。完整调用路径、日志、次要候选和迁移细节放在后续章节或可展开区域，重要风险仍在总览中可见。用目录和可定位标题支持跳读，避免重复铺陈同一背景。

结束时给出可选择的下一步，例如接受方案、补做实验或保留现状；每个选项说明会得到什么新结果。界面操作本身不代替实施授权。

## 检查

用读者视角分别走一遍快速阅读与深入核查。检查默认视图能否找到决定、图表是否一致、详细证据是否可达、长内容有无溢出，以及键盘和无网络情况下哪些功能可用。实际未做的渲染或交互验证要明确报告。
